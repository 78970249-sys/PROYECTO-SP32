# Roles del agente en xiaozhi.me

Textos para la descripción del rol del agente (modelo DeepSeek V4, voz en español).

| Archivo | Rol |
|---|---|
| [asistente_musical.md](asistente_musical.md) | "DJ UC": recomienda y explica todo tipo de música (no reproduce audio) |
| [asistente_virtual.md](asistente_virtual.md) | "Asistente UC": asistente de escritorio general |

## Cómo usarlos
1. En [xiaozhi.me](https://xiaozhi.me) abre la consola, entra a tu agente y pulsa **Configure**.
2. En la pestaña **Role**, activa **Customize**.
3. Borra el texto de **Role Introduction** y pega el contenido del archivo que quieras.
4. Pulsa **Save** y presiona **RST** en la placa para que cargue el nuevo rol.
